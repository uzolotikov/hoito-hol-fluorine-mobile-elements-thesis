# Гены устойчивости к фториду на плазмидах и конъюгативных элементах в метагеноме источника Хойто-Гол

Код и данные для повторения анализа из тезиса:

> Гильманова А.Р., Золотиков У.Е., Тощаков С.В. Гены устойчивости к фториду на плазмидах и
> конъюгативных элементах в метагеноме источника Хойто-Гол // _[ЗАПОЛНИТЬ: конференция, город, год, страницы]_.

НИЦ «Курчатовский институт», Москва. Контакт: gilmanovaalina8@gmail.com

## Что проверялось

Вода минерального источника Хойто-Гол содержит 3,4–3,5 мг/л фторида. Работа отвечает на вопрос, связаны ли
гены выведения фторида с мобильными генетическими элементами: с транспозазами или с плазмидами.

Анализ повторён на трёх сборках одного метагенома:
- только из коротких прочтений Illumina;
- гибридной, из прочтений Illumina и Nanopore;
- только из длинных прочтений Nanopore.

Результат кратко:
- Найдено 10 различных локусов «фторидный рибопереключатель RF01734 + ген экспортёра CrcB или CLCᶠ».
- Транспозаз рядом с экспортёрами не больше, чем ожидается случайно, ни в одной сборке.
- Среди контигов с локусами плазмидных больше ожидаемого в сборке из коротких прочтений и в гибридной.

## Данные

Анализ начинается с трёх сборок. Где их взять, описано в [data/README.md](data/README.md). Команды, которыми
сборки получены из прочтений, приведены в `workflow/assembly.sh`.

Профили Pfam и модель Rfam лежат в `resources/models` в том виде, в каком использованы в работе. Пороги GA
зависят от релиза базы, поэтому файлы приложены, а не скачиваются.

| Файл | Источник |
|---|---|
| `crcb.hmm`, `clc.hmm` | Pfam 33.1: CRCB (PF02537), Voltage_CLC (PF00654) |
| `mge_146.hmm` | 146 профилей транспозаз, интеграз, рекомбиназ и резольваз: 140 из Pfam 33.1 и 6 из более позднего релиза; список в `resources/mge_profiles.tsv` |
| `plasmid_markers_29.hmm` | 29 профилей Pfam 33.1 для генов репликации, мобилизации, конъюгации и разделения плазмид; список в `resources/plasmid_marker_profiles.tsv` |
| `RF01734.cm` | Rfam 15.1, фторидный рибопереключатель |

Pfam и Rfam распространяются по лицензии CC0. Контрольные суммы распакованных файлов — в `resources/models.md5`.

База geNomad 1.9 скачивается с Zenodo, [запись 14886553](https://zenodo.org/records/14886553).

`resources/clc_refs.faa` содержит 16 белков CLC из UniProt: 10 из клады CLCᶠ и 6 хлоридных каналов ClcA и ClcB.
По ним на дереве отделяется клада CLCᶠ.

## Установка

```bash
mamba env create -f envs/analysis.yml    # анализ и рисунки
mamba env create -f envs/genomad.yml     # geNomad ставится отдельно из-за зависимостей
mamba env create -f envs/assembly.yml    # нужно только для сборки из прочтений
```

Программы конвейера должны быть доступны в `PATH`. Например, активируйте `hoito-fluoride`, а путь к `genomad`
из окружения `hoito-genomad` добавьте в конец `PATH`.

## Запуск

```bash
cp config.example.sh config.sh       # указать пути к сборкам и число потоков
bash workflow/run_all.sh
```

`run_all.sh` выполняет шаги по порядку. Их можно запускать и по одному.

| Шаг | Что делает |
|---|---|
| `00_databases.sh` | Распаковывает модели из `resources/models`, скачивает базу geNomad |
| `01_annotate.sh <имя> <fasta>` | Контиги ≥ 1000 п. н.; гены Prodigal; поиск CrcB, CLC и 146 профилей МГЭ с порогами GA; поиск RF01734; дерево белков CLC |
| `02_loci.py out/<имя>` | Клада CLCᶠ по дереву; локусы; транспозазы в окнах ±10 генов; выбор контрольных контигов |
| `03_genomad.sh <имя>` | geNomad на контигах с находками и контрольных; маркерные гены плазмид на контигах с локусами |
| `04_plasmids.py out/<имя>` | Тест на избыток плазмидных контигов |
| `05_compare.sh` | Сверка локусов между сборками и итоговые таблицы в `out/results` |

### Методика

- **Локус.** Рибопереключатель RF01734 и ген экспортёра на одной цепи; ген ниже рибопереключателя, промежуток
  не больше 200 п. н.
- **Клада CLCᶠ.** На дереве белков PF00654 выбирается разрез, лучше всего отделяющий референсы CLCᶠ от ClcA и ClcB.
- **Транспозазы.** Гены с доменами из 146 профилей в окне ±10 генов вокруг генов CrcB и CLCᶠ. Ожидаемое число
  считается по доле таких генов в той же сборке отдельно для контигов < 5, 5–20, 20–100 и > 100 тыс. п. н.
  Значимость по биномиальному распределению.
- **Плазмиды.** Контиг плазмидный, если geNomad с порогами по умолчанию включил его в список плазмид. На каждый
  контиг с локусом берётся до 60 контигов той же сборки длиной ±25 % без находок. Ожидаемое число плазмидных
  контигов равно сумме долей плазмид в этих контрольных наборах. Значимость по пуассон-биномиальному распределению.
- **Сверка сборок.** Участок локуса с флангами по 300 п. н. ищется blastn в другой сборке. Локусы считаются
  одним, если выравнивание с идентичностью ≥ 99 % покрывает ≥ 90 % самого локуса и перекрывает локус другой
  сборки. Фланги в критерий не входят, потому что у краёв контигов сборки расходятся.

## Результаты

Конвейер пишет итоговые таблицы в `out/results`. Их копии, полученные на данных работы, лежат в `results/`.

| Файл | Содержание |
|---|---|
| `results/loci_across_assemblies.tsv` | 10 различных локусов, их контиги в трёх сборках, оценка geNomad и маркерные гены плазмид |
| `results/enrichment_tests.tsv` | Тесты на транспозазы и плазмиды по каждой сборке |
| `results/assembly_stats.tsv` | Характеристики сборок и число находок |
| `results/<сборка>/` | Локусы, контиги с локусами, все гены экспортёров и журналы шагов по каждой сборке |

| Сборка | Транспозаз найдено / ожидалось | P(X ≥ k) | Плазмидных контигов с локусами | Ожидалось | P(X ≥ k) |
|---|---|---|---|---|---|
| только короткие прочтения | 1 / 3,9 | 0,98 | 3 из 9 | 0,13 | 1,5·10⁻⁴ |
| гибридная | 3 / 6,2 | 0,95 | 4 из 9 | 0,34 | 1,6·10⁻⁴ |
| только длинные прочтения | 5 / 6,6 | 0,79 | 1 из 6 | 0,13 | 0,13 |

Из 10 локусов 6 найдены во всех трёх сборках, 3 только в сборке из коротких прочтений и гибридной, 1 только в
гибридной и metaFlye. В гибридной сборке плазмидным назван и контиг `NODE_1127` с двумя локусами
*Pannonibacter*, но маркерных генов плазмид на нём нет.

Числа в тезисе получены этим конвейером.

Один белок CLC, `NODE_296_length_44913_cov_1.523095_34` в сборке из коротких прочтений, стоит на границе
клады CLCᶠ, и его отнесение зависит от порядка последовательностей при построении дерева. Здесь порядок
зафиксирован сортировкой по имени. В локусы этот белок не входит.

## Ограничения

- Элемент *Hydrogenophaga* может быть плазмидой или интегративным конъюгативным элементом; это не установлено.
- Контиг *Ideonella* длиной 457 тыс. п. н. несёт гены репликации плазмидного типа, но мегаплазмида это или
  фрагмент хромосомы, не установлено.
- Прямой проверки горизонтального переноса, например сравнения деревьев экспортёров и геномов-хозяев, в работе нет.
- Таксоны локусов взяты из MAG; биннинг в конвейер не входит.
